# Prototypes index

Throwaway, spec-free single-HTML files to *see* design options before writing design rules.
Open directly in a browser (fonts load from Google Fonts, so online for now). Judge them
**through a Teams screen-share**, not just locally.

| File | Tests | Verdict |
| --- | --- | --- |
| `01-palette-type.html` | Paper tone, charcoal text, green accent usage, 3 serif/sans pairings, type scale at share size | pending |
| `02-chapters-depth.html` | Snapping chapter scroll, persistent title bar + agenda nav, bokeh depth, key-message frosted overlay, fireflies (off/subtle/present) | pending |
| `03-notes-spotlight.html` | Reader-notes overlay: blur-everything-but-target spotlight + callouts + citations | pending |
| `04-diagram-swarm.html` | Dynamic message-board swarm diagram in two styles (line-drawn vs soft-node) with step builds | pending |

**Palette constraint carried by every prototype:** accent `#86BC25` is 2.0:1 on paper, so it's
for fills, glows, strokes, never text. Accent-as-text uses deep green `#4B6E10` (5.4:1).
