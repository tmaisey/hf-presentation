## Reader notes
### Note 1 (for #s5-array): One array per roof
Each roof’s array feeds that block’s landlord supply, which runs the shared parts of the building and offsets daytime power bought from the grid. Installer quotation Q-2291, §2
- source: Installer quotation Q-2291, §2 <https://installer.example.org/quotes/q-2291>
### Note 2 (for #s5-flats): How a flat sees the saving
Flats see a monthly credit, split pro rata to each flat’s daytime use. Installer quotation Q-2291, §2
- source: Installer quotation Q-2291, §2 <https://installer.example.org/quotes/q-2291>
### Note 3 (for #s5-upkeep): Upkeep
One inspection and panel clean a year. The five-year service plan covers it; afterwards it costs £1,150 a year for both roofs. Installer quotation Q-2291, §5
- source: Installer quotation Q-2291, §5 <https://installer.example.org/quotes/q-2291>
