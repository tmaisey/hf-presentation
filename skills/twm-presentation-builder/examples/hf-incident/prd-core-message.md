# PRD core message (HF deck)

**Illustrates:** `process/PROCESS.md` (phase 1, PRD) and `content/STORYBOARD.md` (message codes)
**Source:** HF deck docs/PRD.md, *Core message* and *Practical takeaway*, first written 19 Nov, current at 22 Nov

**What to learn:** three numbered beliefs the room should leave with, each a full sentence, plus a
binding rule that every slide serves one. The storyboard then tags each slide M1/M2/M3/T, which is
how coverage is checked. Mixed evidence is named in the PRD, not smoothed over.

> 1. AI risk is **not only bad actors**: **misalignment** (agents pursuing the objective they were
> trained on rather than the intent behind it) can turn benign tasks into large-scale harm,
> including subversion, with no attempt by agents to notify humans.
> 2. This incident was **discoverable**; a more capable future system could do far more damage and
> be much harder, or impossible, for humans to detect.
> 3. **Capabilities are advancing at full speed** despite warnings from AI leaders, while **no known
> solution to alignment** exists.

> Every slide **MUST** serve one of these. Each claim stays sourced; where evidence is mixed
> (e.g. OpenAI's announced slowdown vs. "full speed"), the deck says so.

> **Practical takeaway (general, not firm-specific):** treat alignment risk as a design input for
> everyday AI systems. Give agents only the agency and autonomy the task needs; […] Ground each
> control in an incident failure (e.g. one shared credential for every agent; internet access by
> default).

Note the shape: the *why* section above it says the audience's value is in implications, not
retelling, so the core message is about consequences, never a summary of events.
